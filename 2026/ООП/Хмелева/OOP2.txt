операции сравнения перегружаются только в паре

Наследование
Наследовать можно от простого класса от абстрактного и от интерфейса
В C# можно наследоваться только от одного класса множественное наследование запрещено, но реализуется через интерфейсы

Зависимость (слайд 9 Driver использует Car)

Наследование приментся только для классов и интерфейсов 
Структуру перечисления и делегаты не наследуются



Преобразование типов
Upcasting
Преобразование от потомка к предку делается автоматически

Downcasting
Преобразование от предка к потомку требует явного преобразования


explicit
существует возможность преобразовать один тип к другому причем эти типы могут быть не связаны наследованием
через оператор 
class MyClass{
	public static explicit operator OtherClass(MyClass mc)
	{
		OtherClass oc = new OtherClass();
		oc.field = mc.field;
		return oc;
	}

}

static void Main()
{
	MyClass r =  new MyClass();
	MyClass.OtherClass oc = (OtherClass) r;

}


implicit

class Myclass
{
	public static implicit operator MyClass(OtherClass oc)
	{
		MyClass mc = new MyClass();
		oc.field1 = mc.field1;
		oc.field2 = mc.field2;

		return mc;
	}

}
