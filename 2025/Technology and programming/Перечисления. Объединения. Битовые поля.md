Перечислением называется тип данных который включает множество именованных целочисленных констант. Эти именованные константы надлежащие перечислению, называются перечислимыми константами.
Синтаксис:
```c++
enum -> имя_типа_перечисления {
	A,
	B,
	C
};
```
где `enum` ключевое слово, A,B,C перечислимые константы. При объявлении типа перечисления его значения могут инициализироваться произвольными целочисленными константами. Если же инициализация отсутствует то перечислимым константам присваивается последовательные значения от нуля. Переменным перечислимого типа можно присваивать только именованные значения перечислимых констант. Например:
```c++
int A = B
```

# Объединения 
Тип объединения описывает набор данных которые называются элементами или членами объединения. Объединения позволяют хранить в одной и той же области памяти значения различных типов которые соответствуют, типам элементам объединения, но в каждый данный момент времени в этой области памяти может храниться только одно значение. Отсюда следует что длина памяти распределяемая компилятором под объединение равна наибольшей из длин членов этого объединения. Синтаксис: 
```c++
union имя_объединения {
	int N;
	double C;
};
```
union - это ключевое слово N и C это члены объединения 
При объявлении переменной типа объединения её можно инициализировать значением которое должно иметь тип первого члена объединения. Например:
```c++
union num A = {1};
```
Как и в случае со структурами для доступа к элементу объединения используется оператор "." объединения одного типа можно присваивать друг другу. 

# Битовые поля
Битовым полем называется член структуры или объединения который объединяет последовательность бит. Битовое поле может иметь один из следующих типов: `int` `unsigned` `signed` при объявлении битового поля после его имени указывается длина поля в битах Например:
```c++
struct A {
	int B:6;
}
```
Длина битового поля B равна 6, длина должна быть неотрицательным целым числом и не должна превышать длины базового типа данных битового поля. Инициализируются битовые поля также как и обычные элементы структуры, например:
```c++
A = {0, 1, 2, ...}
```
Доступ к элементам битового поля, осуществляется так же как и доступ к обычным элементам структуры битовые поля могут использоваться в выражениях точно так же как и переменные базового типа битового поля. Обычно битовые поля используются для установки различных флагов
