Файловые ввод\вывод ничем не отличаются от консольного, за единственным исключением если данные читаются из файла, то в любой момент можно вернутся к началу файла и с читать всё заново. Для того чтобы в C++ работать с файлами необходимо подключить библиотеку \<fstream\> 
```c++
#include <fstream>
```
После этого можно объявлять объекты привязанные к файлам для чтения данных из файла и для записи данных в файл. 
`ifstream in` - этот поток используется для чтения
`ofstream out` - это поток который используется для записи
Чтобы привязать тот или иной поток к файлу используется метод `open()` например
```c++
in.open("1.txt");
out.open("2.txt");
```
При работе с файлами используются операторы `in` вместо `cin` и `out` вместо `cout` 
Для закрытия ранее открытого файла используется метод `close()` например:
```c++
in.close();
out.close();
```
Закрытый файловый поток можно переоткрыть заново при помощи метода `open()` 
При считывании данных из файла может произойти ситуация достижения конца файла (`EOF`), после достижения конца файла никакое чтение из файла невозможно. Данный метод возвращает `true`, если достигнут конец файла или `false` если не достигнут. Состояние файлового потока можно проверить если просто использовать идентификатор потока в качестве логического условия. 
Например:
```c++
if(in)
```
также можно использовать в качестве условия результат возвращаемый операцией считывания, если считывание было удачным то результат считается `true`, а если неудачным тогда `false`.
