Функции определяют действия которые выполняет программа, они позволяют выделить набор инструкций и назначить ему имя. А затем многократно по присвоенному имени вызывать в различных частях программы. Функция это именованный блок кода. 
Синтаксис функций:
```c++
[тип] [имя функции] (параметры)
```

Для возвращения результата функции применяется оператор `return`. Если функция имеет в качестве возвращаемого типа любой тип кроме `void`, то она должна обязательно с помощью оператора `return` возвращать какое-либо значение. Возвращаемым типом функции `main` является тип `int`  поэтому функция должна использовать оператор `return`, и возвращать какое-либо значение. Язык C++ позволяет не использовать оператор `return` в главной функции main. 
Если функция имеет тип `void` то ей не надо ничего возвращать. Например можно определить функцию которая просто выводит текст на консоль. 
При запуске программы на C++  запускается функция `main` другие функции определенные в программе автоматически не выполняются, их надо вызывать. 
Например определим и выполним следующую функцию: 
```c++
void hello()
{
    std::cout << "hello" << std::endl;
}
 
int main()
{
    hello();
    hello();
}
```

Здесь определена функция `hello`, которая вызывается в функции `main` два, раза в этом и заключается преимущество функций, т.е. можно вынести некоторые общие действия и затем вызвать многократно в различных местах программы. 
При использовании функции компилятор должен знать о функции до её вызова, поэтому вызов функции должен быть после её определения. 

### Перегрузка функций
При определении функции нужно указать тип возвращаемого функцией значения, а также количество параметров и тип каждого из них. C++ позволяет определять несколько функций с одним и тем же именем. В процессе компиляции C++ принимает во внимание количество аргументов используемых каждой функцией, а затем вызывает именно требуемую функцию, предоставление компилятору выбора среди нескольких функций называется ***перегрузкой***.
Перегрузка является особенностью языка C++ которой нет в языке C, которая улучшает удобочитаемость программ. Перегруженные функции не обязаны возвращать значения одинакового типа, по той причине что компилятор идентифицирует функцию по её имени и её аргументам, потому что для компилятора функции с одинаковыми именами но различными типами аргументов - это разные функции. Это упрощает программирование позволяя программистам работать только с одним именем функции.
